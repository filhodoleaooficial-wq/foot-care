Comandos para enviar para o GitHub:

# Verificar status dos arquivos
git status

git add .
 
# Fazer commit
git commit -m "sua mensagem do commit"
 
# Enviar para o GitHub
git push
Se for a primeira vez:



bash
# Configurar branch upstream
git push -u origin main
Para adicionar arquivos específicos:




bash
git add arquivo1.js arquivo2.css
Para ver o que será commitado:




bash
git diff --cached

Você já está no repositório. Para fazer commit e push das mudanças:



bash
# Adicionar todas as mudanças
git add .
 
# Fazer commit
git commit -m "atualizações"
 
# Enviar para o GitHub
git push

O diretório mastery-pesdeseda - Parece que você clonou o repositório dentro dele mesmo. Isso pode causar problemas. Recomendo remover esse diretório antes do commit:
